# PocketDex

A Pokémon data exploration and battle analysis system that visualizes structured Pokémon data, including stats, abilities, and computed damage relationships.

## Overview

PocketDex is a full-stack React application that consumes external Pokémon data and transforms it into structured, interactive visualizations. Beyond basic data browsing, the system includes computed battle logic to generate damage relationships and stat comparisons between Pokémon.

The goal of this project is to combine API-driven data ingestion with client-side computation and visualization logic.

---

## Features

- Pokémon search and detailed data exploration
- Dynamic routing for individual Pokémon profiles
- Full stats and ability visualization
- Type-based relationship rendering
- Automated damage calculation system for battle comparisons
- Structured data transformation from external API responses
- Responsive UI for desktop and mobile use

---

## Tech Stack

- React
- JavaScript
- REST API integration (Pokémon API)
- CSS

---

## System Notes

- External API is used as the base data source
- Client-side logic transforms raw API data into structured battle and stat models
- Damage calculation system computes comparative effectiveness between Pokémon types
- Designed as a data transformation + visualization layer, not just a UI wrapper
